Privacy policy

What PingSafe keeps, and for how long

Last updated: 14 November 2026. Contact: ramanujdodiya22@gmail.com

PingSafe connects two phones: one person can ask where the other is ("ping"), and the other answers with one tap or automatically. There is no live tracking: a location is read only when someone answers a ping, sends a check-in, or when the low-battery alert they turned on fires.

No accounts

PingSafe has no sign-up, email or password. Each phone gets a random device ID and a secret key when it is set up. The server stores the ID and a one-way hash of the key.

What the server receives and keeps

  • Answers: location (latitude, longitude, accuracy, place name), battery level, charging, network type and time. Only the latest answer is kept, for one hour, so the other phone can load it.
  • Delivery records for reliability and speed measurements: timings, phone model, network type and whether it worked. No location. Only the most recent records are kept (a fixed number, oldest removed first).
  • Pairing: which two device IDs are paired and their settings (answer mode, low-battery alert level, quiet hours with time zone, timed pings). Removed 7 days after unpairing.
  • First names while pairing: the first name typed when inviting or joining, and the relationship chosen for an invite. Deleted as soon as the invite is accepted, cancelled or expires, or the pairing request is approved or declined.
  • Streak: the dates (not times or places) on which the sharing phone answered, and its time zone.
  • Push address: the phone's Firebase installation ID, so pings can reach it. The device ID, key hash and push address are kept until you ask us to delete them.
  • IP addresses are used briefly for abuse limits (e.g. code guessing) and are not stored with answers.

What stays on the phones only

  • The name and phone number you save for the other person.
  • The log: the last 50 pings, answers and check-ins, with time, how, and where the location was, so you can open a place again in Maps. It is never uploaded. Uninstalling PingSafe or clearing its data deletes it.

Who else is involved

  • Google Firebase Cloud Messaging delivers the pings. Pings carry only IDs and preset keys, never names or places.
  • Upstash (Redis) stores the server data above.
  • Counts for measuring PingSafe: daily totals (for example how many pings were sent and answered), how long answers took (including the time from tapping Ping to seeing the answer, sent by the checking phone as a number only), and an estimate of how many phones used PingSafe each day and week. The estimate uses a method (HyperLogLog) that can count phones but cannot list or identify them. None of these include names, places, phone numbers or IDs.
  • During testing, PingSafe's server runs on The Vibe Hosting, on machines in Germany (Hetzner).
  • GitHub hosts the app's download file. Test versions of the app ask GitHub about once a day whether a newer version exists (this can be turned off in Settings), and download it only when you tap Update. GitHub sees your phone's IP address, as with any download; nothing about you or your pairing is sent.
  • Map pictures are drawn by Google Maps on the checking phone. Google sees roughly which area was viewed; see Google's privacy policy.
  • The phone's own place-name lookup (Android Geocoder) turns coordinates into a place name.

We do not sell data, show ads, or share data with anyone else.

Background location

"Allow all the time" is asked for only for auto-answer and the low-battery alert. Even then, the location is read only when a ping arrives or once when the battery reaches the chosen level. The person sharing gets a notification every time their location is sent.

Your choices

  • Unpair at any time in Settings, on either phone. The latest answer is deleted at once.
  • Turn off auto-answer, the low-battery alert or timed pings with one tap.
  • Uninstall PingSafe or clear its data to delete everything on the phone. If one phone does this, the other is unpaired automatically.
  • To have any server data deleted sooner, write to the contact address above.

Security

Everything travels over encrypted connections (HTTPS). Data on the server is not yet end-to-end encrypted.

Children

PingSafe is not directed at children under 13. A parent who uses it with a child should set it up together.
